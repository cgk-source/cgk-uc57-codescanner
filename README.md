# Code Scanner

An AI-assisted code review and security scanner for code diffs and Azure DevOps pull requests.

## Planned Stack

- ASP.NET Core 8 Web API
- React and TypeScript
- Azure OpenAI GPT-4o
- Azure SQL Database
- Azure DevOps REST API
- Azure Key Vault and Application Insights
